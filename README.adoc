= Garland

This repository contains all my NixOS configurations.

== Configurations

All my configurations are named after poisonous plants, not because I am toxic, but because I think they are cool.

* **Wisteria**: my desktop computer 
* **Foxglove**: my framework laptop
* **Hemlock**: my VPS machine
* **Ivy**: Home Assistant running on Raspberry PI

== Structure

This repository follows the https://github.com/mightyiam/dendritic[dendritic pattern]: every Nix file under `modules/` is a flake-parts module, discovered automatically with https://github.com/vic/import-tree[import-tree] (files prefixed with an underscore are skipped). Feature modules write into the `flake.modules.nixos.<name>` and `flake.modules.homeManager.<name>` namespaces, and each host (`modules/hosts/<name>`) composes the features it wants by importing them. `modules/nixos-configurations.nix` turns every `hosts/<name>` module into a `nixosConfiguration`.

== Private modules (wreath)

Some modules I want reproducible but not public live in a separate private repo, https://github.com/WJehee/.wreath[wreath].
It follows the same dendritic pattern and exposes its module tree as `flakeModules.default`, which this flake imports as the `wreath` input.
Because both trees write into the same `flake.modules.*` namespaces, a host imports a private feature (e.g. `nixos.hacking`) exactly like a public one.

`just rebuild` runs `nix flake update wreath` first, so every rebuild pulls the latest pushed wreath. To iterate on private modules without pushing, use `just rebuild-wreath`, which overrides the input with a local `../.wreath` checkout.

== Secrets management

Secrets are managed with https://github.com/Mic92/sops-nix[sops-nix]. Encrypted secrets are stored in `secrets/<hostname>.yaml` and decrypted at NixOS activation time using the host's SSH ed25519 key.

=== First-time setup

Export the age private key from the SSH host key (once per machine):

[source,bash]
----
mkdir -p ~/.config/sops/age
sudo nix run nixpkgs#ssh-to-age -- -private-key -i /etc/ssh/ssh_host_ed25519_key > ~/.config/sops/age/keys.txt
----

=== Editing secrets

[source,bash]
----
just secrets <hostname>
----

This opens the decrypted file in your editor. On save, sops re-encrypts automatically.

=== Adding a new host

1. Get the age public key from the host's SSH key:
+
[source,bash]
----
# From the host itself:
cat /etc/ssh/ssh_host_ed25519_key.pub | nix run nixpkgs#ssh-to-age

# Or remotely:
ssh-keyscan -t ed25519 <host> | nix run nixpkgs#ssh-to-age
----

2. Add the key to `.sops.yaml` under `keys:` with an anchor (e.g. `&hostname`), and add a `creation_rules` entry for `secrets/<hostname>.yaml`

3. Create the encrypted secrets file:
+
[source,bash]
----
just secrets <hostname>
----
